# AI Copywriter
Русскоязычный копирайтер и редактор: статьи, коммерческие тексты, посты, интервью, корректура, точечные правки. Версия 1.1.0 — кандидат, качество на моделях пока не подтверждено.
Установка: скопируйте весь каталог в .claude/skills/copywriter (Claude Code) или .agents/skills/copywriter (Codex) проекта. Проверьте обнаружение Skill. Пример: «Используй copywriter. Исправь только орфографию и пунктуацию: …».
Внешние источники и сервисы используются только при наличии доступа и согласия на передачу данных. Локальная диагностика: python scripts/lint_text.py draft.txt. Она не заменяет корректора. Модульные тесты: python -m unittest discover -s scripts -p 'test_*.py'.
Материалы: references/SOURCES.md. Исследование выборочное. Примеры синтетические. Сравнительные evals: evals/README.md.

Дополнительно: scripts/check_revision.py before.txt after.txt START END — диапазон в символах Unicode, нумерация с нуля, END не включён. Сравнивает неизменность текста вне правки. Для официального Главреда требуется отдельный доступ к платному API, см. references/TOOL_CONTRACTS.md.
