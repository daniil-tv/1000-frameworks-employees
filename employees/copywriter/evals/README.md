# Приёмка
Статус: not_run. Выполнять каждый сценарий в новой сессии Claude Code и Codex, с/без Skill, одинаковые данные и доступы, 3–5 повторов. Проверять фактическую активацию по трассе. Критерии не показывать испытуемой модели. Сравнивать слепым экспертным ревью, точные требования — diff/автоматической проверкой. Записывать модель, версию, коммит, вход, выход, результат каждого критерия, критические ошибки, время и токены. Отдельно проверять held-out задачи, не использованные для настройки. Не публиковать реальные материалы в тестах. Цели проекта: >=95% успешности, precision/recall активации >=95%, ноль наблюдаемых критических ошибок, доказанное улучшение baseline. Не утверждать, что эти цели достигнуты без результатов.
