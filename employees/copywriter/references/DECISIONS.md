# Решения редактора
| Симптом | Диагностика | Действие |
|---|---|---|
| Текст непонятен | Читателю не хватает исходного знания или связи между тезисами | Добавить необходимый контекст, затем объяснить механизм |
| Текст длинный | Повтор или необходимая детализация? | Удалить повтор, оставить условия и доказательства |
| Текст рекламный | Оценка без опоры на факт? | Заменить оценку подтверждённым действием, свойством или примером |
| Заголовок слабый | Неясна тема или польза? | Назвать предмет и задачу без кликбейта |
| Нет фактуры | Можно ли дать полезный результат без критического утверждения? | Написать подтверждённую часть, отметить пробел вне текста |
| Есть противоречие | Разные периоды, определения, выборки? | Сверить сопоставимость; не склеивать данные |
| Сложный термин | Аудитория знает его? | Сохранить профессиональный термин или объяснить при первом употреблении |
| Авторская позиция спорная | Мнение или измеренный факт? | Сохранить атрибуцию, проверить фактические основания |
| Сервис подсветил слово | Слово лишнее или выражает условие, связь, вежливость? | Удалить только если смысл сохраняется |
| Пользователь просит «улучшить» | Не определены границы редакторской свободы | Сохранить факты, тон и утверждённые части; задать вопрос при существенном риске |

## Приоритеты при конфликте
Безопасность и конфиденциальность → точность и сохранение смысла → явно заданный объём правок → языковая норма → польза и структура → стиль и краткость → оценка автоматического сервиса.
В корректуре не переписывать предложение ради стиля. Явную фактическую ошибку вынести в замечание; не менять утверждённую цифру без разрешения. Если языковая норма допускает варианты, сохранять авторский выбор.
## Антипаттерны
Не сочинять историю клиента ради вовлечения; не заменять доказательство статистикой без источника; не писать «не просто X, а Y» ради эффекта; не создавать искусственную срочность; не превращать любой текст в список; не удалять оговорки о достоверности; не подменять редактуру сокращением; не обобщать единичное наблюдение до закона рынка.
