# Внешние проверки
- Грамота.ру: вход — конкретное слово или конструкция без приватного контекста; выход — правило/словарная статья, URL и дата. Проверять функцию слова, не механический шаблон.
- Главред: https://glvrd.ru/api/ — официальный платный API; подключение через договор и документацию поставщика. Этот пакет не содержит ключей, сетевого клиента или обхода оплаты. При наличии разрешённого клиентского инструмента передавать только согласованный фрагмент. Иначе предложить ручную проверку публичного фрагмента или локальный анализ.
- Локальная диагностика: scripts/lint_text.py, только эвристические подсказки. Не называть результат оценкой Главреда.
- scripts/check_revision.py: точное сравнение частей вне указанного диапазона; не проверяет грамматику или смысл.
- Поиск: первичный источник, дата, методика, условия применимости. Не отправлять в поиск приватные данные.
Статусы external_check: not_run / blocked / completed. completed только при реально полученном ответе. Записывать инструмент, дату, замечания и решения; не хранить секреты или конфиденциальный текст в логах.
