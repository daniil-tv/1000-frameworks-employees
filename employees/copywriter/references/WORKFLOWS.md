# Рабочие процессы
## W1. Статья
Вход: задача, аудитория, тема, фактура, формат. Определи вопрос, ценность и предел темы. Собери первичные источники, затем структуру. Напиши лид и разделы с примерами, проверь обещание заголовка. PASS: каждый раздел раскрывает вопрос, спорные утверждения атрибутированы, готовый материал не содержит выдуманных сведений.
## W2. Коммерческий текст
Определи сегмент, ситуацию покупки, критерии выбора, реальный оффер и следующее действие. Свяжи функцию с механизмом и пользой. Укажи условия и ограничения. Не изобретай УТП, скидки, гарантии, социальное доказательство. PASS: читатель понимает предложение и может сделать следующий шаг.
## W3. Устная фактура
Сначала прочитай весь доступный источник. Разметь тезисы, цитаты, факты, гипотезы, шум. Для статьи сгруппируй сюжеты; для дословного интервью сохрани порядок и формулировки, исправляй только разрешённое. Проверь все числа и термины. PASS: смысл совпадает с оригиналом, нет выдуманной связи.
## W4. Корректура
Сохрани исходный текст. Исправь объективные языковые ошибки и согласованную типографику; не заменяй синонимами правильные слова. Сомнительные факты отметь отдельно, не исправляй молча. PASS: diff не содержит незапрошенной стилистической правки.
## W5. Точечная правка
Установи разрешённый диапазон. Измени только его; проверь связь с соседними фрагментами, не переписывая их. PASS: остальной текст идентичен.
## W6. Исследование
Формулируй проверяемые вопросы. Для каждого источника сохраняй автора/организацию, дату, URL, утверждение, метод и ограничения. При противоречии не усредняй без основания. Отдельно отмечай недоступное. PASS: фактура проверяема, источники не вымышлены.
## W7. Аудит
Раздели проблемы на фактические, логические, структурные, стилистические и языковые. Ранжируй по влиянию на задачу. Для каждой приведи конкретный фрагмент, проблему и исправление. Не переписывай весь материал, если попросили диагностику.
