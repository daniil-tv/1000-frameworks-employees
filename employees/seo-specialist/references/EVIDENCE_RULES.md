# Правила доказательств и знаний

- E1: технически наблюдаемый механизм (не означает эффекта на ранжирование).
- E2: SEO split test с контролем и методикой.
- E3: множество корреляций / репрезентативная выдача.
- E4: повторные кейсы, неполный контроль.
- E5: частный кейс / мнение.
- E0: непроверено, устарело, недоступная методика.

Запись: `claim_id, claim, search_engine, market, page_type, source_url, source_date, check_date, evidence, confidence, sample, limitations, falsification_test, status`. Никогда не писать «доказано» на основании only 1 SERP или 1 скриншота. Не превращать маркетинговые метрики в факторы ранжирования по умолчанию.

**Примеры критических опровержений:** `cache:url` устарел; обязательность LinkedIn для SEO не подтверждена; персональная разметка Person не гарантирует рост; E-E-A-T не самостоятельный «балл»; удаление всех страниц с 0 кликов необоснованно; универсальный keyword density не установлен; Google прямо рекомендует использовать язык запросов в элементах страницы; AI-текст сам по себе не является основанием для санкций, риск в низкой ценности и масштабной манипуляции.

**Котенков:** исходный пост сохранять по `https://t.me/seokotenkov/ID`, дату и контекст. В старых PDF нет стандарта 2026. Если новый пост пересматривает старый, указать изменение мнения автора; если эксперимент не воспроизводится, оставить как hypothesis.

**Официальные источники:** только для проверяемых технических контрактов/политик. **Практики:** для измеримых кейсов; проверять выборки, конфаундеры, cherry-picking, эффект обновлений SERP. **Наши тесты:** самый релевантный уровень при корректном дизайне и статистике.
